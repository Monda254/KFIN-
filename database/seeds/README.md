# Database Seeds

This directory is reserved for deterministic synthetic seed scripts used during local development and testing.

---

## Seed Data Rules (Section 19 & 20)

- **Exclusively Synthetic:** Real citizen identities, authentic criminal records, or genuine DNA profiles are strictly prohibited.
- **Identifiable Identifiers:** All synthetic records must use obviously artificial prefixes (e.g., `SYNTH-CASE-001`, `SYNTH-SUBJ-001`).
- **Phase 0 Status:** No operational seed scripts exist in Phase 0.
