# AI Development Rules

AI-assisted development is allowed only within the approved KFIN phase scope.

1. Inspect existing code, documentation and the current phase before editing.
2. Treat the Master Specification, phase specification, sub-phase specification and accepted ADRs as authoritative.
3. Ask for clarification or record an ambiguity; do not invent requirements.
4. Do not implement operational case, evidence, laboratory, DNA, persons, intelligence, interoperability or forensic AI functionality in Phase 0.
5. Use synthetic data only.
6. Never fabricate tests, integrations, security status, compliance evidence or forensic results.
7. Never weaken or delete a failing quality gate to obtain success.
8. Report actual commands, results, failures and deferred work.
9. Record material architectural decisions and deviations as ADRs.
10. Stop at the phase boundary. Phase 1 requires a separate authorization and master prompt.
